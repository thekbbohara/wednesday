# Design Styles Vocabulary

Companion reference for the Design Agent. Curated shortlist from "50 Design
Styles Every Designer Should Know for Better Prompting" (uxplanet.org). Use
this when a project or deliverable needs a visual direction - pick a named
style, never a vague mood.

## How to use

1. Start with the style name: "Neo-Brutalist landing page", not "cool bold website".
2. Pick the style from the project's subject, not from taste alone.
3. Mix at most two styles in one hybrid ("Vaporwave x Gothic"). Three or more
   compete and produce mush.
4. When offering the user direction choices, generate the same concept in 3-4
   different styles rather than 4 variations of one.
5. If a style name returns something generic, spell out its core elements from
   the DNA column instead.
6. Write the chosen style name into DESIGN.md before building.
